# 水堀頭的時光信

臺南麻豆地景文學與 Scratch 六年級課程。12 節課，每節 40 分鐘，共 480 分鐘。

- [課程網頁](https://bond0744h871-svg.github.io/madou-scratch-literature/)
- [PowerPoint 教學簡報](materials/madou-scratch.pptx)
- [六階段 Scratch 範例（ZIP）](materials/scratch/madou-all-scratch-projects.zip)

以吳新榮日記和麻豆水堀頭遺址資料入門，透過三幕互動動畫、測試和影片剪輯完成作品。網頁列有課程目標、六次交件、課綱對應與資料來源。

開啟 index.html 可離線閱讀課程。編輯 curriculum.mjs 後執行 `node build-site.mjs` 更新網頁。舊港繪本圖為本課程 AI 生成的想像情境。

Scratch 範例包含第 2、4、6、8、10、12 節版本。Scratch 貓咪取自 Scratch 內建素材，其餘場景為課程用 AI 插圖與片尾文字。第 10、12 節的 .sb3 分別用於錄製與放映，影片由學生錄製、剪輯及匯出。

重新製作 .sb3 可執行 `python build-scratch.py --cat <Scratch貓咪SVG> --font <繁體中文字型>`。需安裝 Pillow。[Scratch 貓咪素材](https://assets.scratch.mit.edu/internalapi/asset/bcf454acf82e4504149f7ffe07081dbc.svg/get/)
