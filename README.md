# 水堀頭的時光信

臺南麻豆地景文學與 Scratch 六年級課程。12 節課，每節 40 分鐘，共 480 分鐘。

- [課程網頁](https://bond0744h871-svg.github.io/madou-scratch-literature/)
- [PowerPoint 教學簡報](materials/madou-scratch.pptx)

以吳新榮日記和麻豆水堀頭遺址資料入門，透過三幕互動動畫、測試和影片剪輯完成作品。網頁列有課程目標、六次交件、課綱對應與資料來源。

開啟 index.html 可離線閱讀課程。編輯 curriculum.mjs 後執行 `node build-site.mjs` 更新網頁。舊港繪本圖為本課程 AI 生成的想像情境。
